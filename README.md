# Catch You Steadily：我会稳稳接住你

> “纵使高空万丈、引力无情，愿这片大地之上的生灵，能有人向你义无反顾地奔赴而来。”

在广袤无垠的 Minecraft 方块世界中，每一次跃向未知的探索，都伴随着与重力的残酷博弈。你是否曾经历过在万仞绝壁边缘手滑失足的窒息瞬间？亦或是搭建高空信标、鞘翅突然失效时的措手不及？当视野中的地表以无可挽回的速度疾速逼近，面对即将到来的落地创伤，除了闭上双眼静待重生，我们是否还能期待一场奇迹？

别担心，**Catch You Steadily** 为每一个在重力面前绝望失重的灵魂，提供了一场充满戏剧性与温暖的双向奔赴。

这不仅是一款打破常规的幽默梗向模组，更是一场关于生命、物理与跨物种羁绊的宏大叙事。当你在高空失重下坠且预计将承受摔落伤害的瞬间，预测落点周围符合条件的原版生物将尝试赶来接住你，放下手头的日常化身守护你的肉盾，展开一场争分夺秒的极速救援，力求以纯正的原版骑乘机制将你稳稳托住！

## 核心亮点：重塑你的下落体验

- **智能落点预测，按需响应**：拒绝无端触发。只有当你处于离地坠落状态、预测轨迹碰撞实体方块且预计将产生摔落伤害时，救援逻辑才会即刻启动。哪怕只是寻常跌落，只要有伤害风险，便不要求达到致命门槛。
- **万物奔赴，为你而来**：在预测落点有效范围内，原版生物将被赋予高优先级的寻路动机，向着你的下落坐标开足马力疾驰。
- **原版骑乘，化解冲击**：当你在半空与赶来的生物在合适时机相遇时，模组将促成骑乘判定。只有骑乘成功建立，本次累积的摔落距离才会被瞬间清零。
- **跨越阵营的无私奉献**：默认情况下，敌对生物同样具备大爱。无论是僵尸还是苦力怕，都会争先恐后赶来充当你的救命肉垫（当然，支持灵活配置排除）。
- **着陆结算自由掌控**：默认在安全平稳落地后优雅放下玩家；亦可配置保持骑乘状态，让你落地后继续留在生物背上。
- **极致纯粹的服务端体验**：不引入繁琐的客户端按键绑定，不新增任何额外 GUI 与复杂渲染管道，保持游戏原汁原味的轻量与纯粹。

## 机制原理：几何预测与原生寻路的融合

生物是如何在浩瀚的世界中精准捕捉下落轨迹并展开救援的？背后是一套融入原版行为树与运动预测的协同机制：

1. **下落侦测与轨迹演算**：
   服务端实时追踪具有向下位移的下落玩家。通过前向模拟运算，判断玩家落点是否为实体方块，并评估是否会产生摔落伤害。若预测落点落入深水等安全介质或无伤害威胁，系统将保持静默。
2. **局部高效生物调度**：
   拒绝全图无差别扫描。系统仅在预测落点周围的有效空间范围内检索已加载的生物实体，精准调度救援力量，避免无意义的算力浪费。
3. **原生目标注入，绝非强行仇恨**：
   救援机制绝不通过强行篡改生物的攻击仇恨来实现，而是向生物的原生寻路目标选择器注入临时的高优先级移动目标。救援结束后即刻清除临时目标，完全不破坏生物固有的底层行为树。
4. **骑乘判定与冲击清零**：
   当坠落中的玩家与赶到的生物发生重叠并满足时机条件时，系统促成原版骑乘交互。骑乘一旦确立，本次下落造成的摔落距离当场清零，使你免受落地冲击之苦。
5. **着陆还原与现场解散**：
   伴随着陆结算完成，注入的临时救援目标被安全移除，现场生物回归各自的平静日常。

## 现实物理与生存法则（重要免责声明）

虽然“稳稳接住”描绘了一幅温情脉脉的画面，但在 Minecraft 真实的物理引擎与复杂地形面前，请务必保持对客观规律的清醒敬畏：

- **生物赶路需要物理时间**：生物受限于自身的原生移动速度、碰撞体积以及地形障碍（例如悬崖绝壁、深坑沟壑、栅栏阻隔）。若你的下落高度极为有限导致滞空时间极短，或者方圆之内根本没有可用生物，救援很可能无法及时送达。
- **落地之后绝无持续免伤**：成功骑乘仅清零**本次累积的摔落距离**，模组不提供持续免伤。如果挺身而出接住你的是一位热心的苦力怕或僵尸，落地解除骑乘之后，请务必立刻拔剑应对现实的残酷。
- **保留骑乘不等于掌控意志**：即便启用保持骑乘选项，这也仅仅保留了你身处生物背上的状态，**绝不会赋予你操控该生物移动、转向或飞行的能力**。
- **非无条件上帝模式**：模组不包含虚空瞬移、死里逃生锁血等任何破坏生存平衡的神仙机制。“我会稳稳接住你”是一份真挚的承诺，但绝非一张万无一失的意外保险。

## 平台支持与版本矩阵

为了确保在不同时代和架构下的最佳适配，本项目针对以下六个目标分别提供独立 JAR：

| 模组加载器 (Loader) | 目标 Minecraft 版本 | 说明 |
| :--- | :--- | :--- |
| **Forge** | `1.7.10` | 经典复古生态适配 |
| **Forge** | `1.12.2` | 黄金期成熟版本适配 |
| **Forge** | `1.20.1` | 现代稳定版适配 |
| **Fabric** | `1.20.1` | 服务端运行环境，依赖对应版本的 Fabric API |
| **Fabric** | `1.21.1` | 服务端运行环境，依赖对应版本的 Fabric API |
| **NeoForge** | `1.21.1` | 现代前沿生态适配 |

请注意：项目不提供跨版本的全能总包，各个版本之间独立分包、互不通用。目前暂未发布正式 Release，所有包体均需通过源码构建获取。

## 安装与运行环境指南

为了获得最稳定可靠的游戏体验，请仔细阅读以下安装与环境要求：

- **服务端部署推荐**：强烈建议将对应加载器版本的 JAR 文件放置在**专有服务端（Dedicated Server）的 `mods` 目录**中。
- **Fabric 运行环境须知**：Fabric 分包元数据明确限定为服务端专用（`environment: server`），且仅注册了服务端入口（`entrypoints.server`）。这意味着**单机集成服务器（单人游戏内置服务端）不会初始化该模组**，且运行环境必须安装对应版本的 **Fabric API**。
- **其他加载器单机兼容性**：Forge 及 NeoForge 目标在单机客户端与纯客户端免装场景下的表现尚未经过全面验证，因此目前不作笼统承诺，推荐优先作为专用服务端模组进行部署。

## 配置体系

为贴合不同平台的开发与运行环境，模组针对各目标采用以下配置方案：

- **Forge 1.7.10 / 1.12.2**：使用经典 `.cfg` (CFG) 文件；
- **现代 Forge (1.20.1) / NeoForge (1.21.1)**：接入其模组加载器提供的 COMMON `.toml` (TOML) 配置；
- **Fabric (1.20.1 / 1.21.1)**：由模组自行读写 Gson `.json` (JSON) 配置文件。

### 核心配置项解析

配置参数在服务端启动时一次性加载为快照。修改配置前必须先停止服务端，完成文件编辑后再启动服务端方可生效：

- **`exclude-hostile`** (布尔值，默认 `false`)
  是否排除敌对生物。默认为 `false`，即苦力怕、僵尸、骷髅等敌对实体均会热心救人；设为 `true` 则仅允许被动与中立生物响应召唤。
- **`excluded-entities`** (列表/数组，默认空列表 `[]`)
  黑名单过滤机制。以各配置格式所规范的数组或列表语法填入生物注册 ID（例如 `minecraft:creeper`），显式拒绝指定生物参与救援。禁止将其理解为统一的逗号分隔字符串。
- **`attraction-radius`** (浮点数，有效范围 `1.0 ~ 32.0`，默认 `24.0`)
  预测落点周围水平搜寻生物的检测半径（以方块为单位，支持小数）。
- **`vertical-range`** (浮点数，有效范围 `1.0 ~ 16.0`，默认 `12.0`)
  预测落点垂直上下搜寻生物的检测深度（以方块为单位，支持小数）。
- **`keep-riding`** (布尔值，默认 `false`)
  落地后的骑乘状态保留。默认为 `false`，在安全着陆后自动解除骑乘；设为 `true` 则在着陆后继续保持骑乘状态，但不会赋予玩家任何操纵坐骑的能力。

关于各配置格式的具体语法示例与参数细节，请参阅[配置与构建说明](common/README.md)。

## 从源码构建

本项目采用 Gradle 多模块架构进行组织管理。你可以在仓库根目录下直接通过 Gradle Wrapper 运行统一发布构建命令：

```bash
./gradlew buildReleaseJars
```

构建执行完成后，六大目标的 JAR 产物将**分别生成在各子模块对应的 `build/libs` 目录中**。请注意，构建脚本不会自动将产物汇总复制到 `build/release`，亦不存在所谓打包汇总的单一总 JAR。

有关历史版本独立构建工具链（JDK 25 要求与 Legacy 目录构建说明）以及各模块详细产物路径，请参阅[配置与构建说明](common/README.md)。
