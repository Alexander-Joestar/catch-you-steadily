# Catch You Steadily：我会稳稳接住你

> 你负责自由落体，附近的生物负责尽力赶来。

在 Minecraft 的世界里，有些相遇源于命运，有些相遇源于你从悬崖上手滑。

**Catch You Steadily** 是一个关于下落、相遇与生物寻路的 meme Mod。当你下落且预计会受到摔落伤害时，预测落点附近的生物会尝试赶来接住你。这不仅是一次与重力的较量，更是一场跨越物种的双向奔赴。

当然，重力没有签署这份情书，生物也不一定赶得上。

## 这一刻，谁会接住你？

当符合条件的下落发生时，附近符合条件的生物会向预测落点寻路。玩家与生物在合适的时机相遇时，Mod 会尝试让玩家骑到生物背上；只有骑乘成功，才会清零本次摔落距离。坐骑安全落地后，默认自动放下玩家；启用 `keep-riding` 可以继续保持骑乘，但不会赋予玩家新的坐骑控制能力。

默认情况下，敌对生物也可以参与救援。你可以排除敌对生物，或按实体注册 ID 排除指定生物。救援通过临时添加寻路目标实现，不会为此设置攻击目标；被接住后，仍要留意生物原有的行为。

**“我会稳稳接住你”是一句美好的愿望，不是一份摔落保险。** 生物需要时间赶路，导航、距离和地形都可能让救援失败。Mod 不提供持续免伤，也无法保证每次都能接住你。它只在预测落点附近搜寻生物，不扫描整个世界，也不通过视线过滤。

## 支持的版本

共用的救援算法分别构建为六个独立 JAR，请选择与你的游戏版本和加载器匹配的文件：

| 加载器 | Minecraft 版本 |
| --- | --- |
| Forge | 1.7.10、1.12.2、1.20.1 |
| Fabric | 1.20.1、1.21.1 |
| NeoForge | 1.21.1 |

没有适用于所有版本和加载器的通用 JAR。Mod 不新增 GUI 或渲染内容。

## 安装

在专用服务器上安装对应版本的加载器，将匹配的 Mod JAR 放入服务器的 `mods` 目录。Fabric 版本还需要安装对应版本的 Fabric API。

Fabric 分包目前使用 `environment: server` 和服务端入口，单机集成服务器不会初始化该 Mod。其他加载器目标的单机及客户端免装情况尚未全面验证。

## 配置

旧版 Forge 使用 CFG，现代 Forge 和 NeoForge 使用 TOML，Fabric 使用 JSON。配置只在服务器启动时读取；修改前请停止服务器，修改后启动服务器生效。

- `exclude-hostile`：默认 `false`，包含敌对生物；设为 `true` 后排除它们。
- `excluded-entities`：默认空列表，可按实体注册 ID 排除生物。列表语法取决于配置格式。
- `attraction-radius`：水平搜寻半径，默认 24 格，范围 1 至 32，可使用小数。
- `vertical-range`：落点上下的搜寻范围，默认 12 格，范围 1 至 16，可使用小数。
- `keep-riding`：默认 `false`，坐骑安全落地后自动解除骑乘；设为 `true` 后保持骑乘。

配置文件路径和具体语法见[配置与构建说明](common/README.md)。

## 从源码构建

在仓库根目录运行：

```bash
./gradlew buildReleaseJars
```

六个 JAR 分别生成在各模块的 `build/libs` 中，不会自动汇总到 `build/release`。构建先决条件和各产物路径见[配置与构建说明](common/README.md)。
