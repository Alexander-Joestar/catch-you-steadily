# Catch You Steadily：我会稳稳接住你

这是一个将大语言模型（GPT）经典安慰口癖在 Minecraft 中按字面实现的梗向模组（Meme Mod）。

在日常对话中，无论用户遇到何种困境或倾诉焦虑，AI 助手总喜欢用温和且笃定的客服语气回应一句经典的口癖：“别担心，我会稳稳接住你。”

本项目将这句充满既视感的口头承诺字面物理化：当玩家在高空失足坠落时，周围的原版生物会放下日常活动，朝着玩家的预测落点狂奔而来，尝试在落地瞬间充当肉垫将玩家接住。

---

## 经典场景重现

> **坠落玩家**：救命！我在两百格高空失足下落，底下全是石头，马上要摔死了！  
> **GPT 助手**：请先深呼吸，我完全理解你面对重力加速度时的无助与不安。请放下焦虑，无论发生什么，我都会稳稳接住你。  
> **附近路过的僵尸与奶牛**：（收到寻路目标，中断日常游荡，全速冲向落点）

---

## 游戏机制与物理限制

戏仿对话中的口头承诺属于艺术夸张，实际救援受 Minecraft 原生机制与物理规律严格制约：

- **生物赶路需要时间与可行路径**：生物依赖原生寻路与移速奔跑，受悬崖、深坑、墙壁或栅栏阻挡。若下落高度过低导致滞空时间不足，或周边没有可用生物，救援将无法送达。模组不提供瞬移、隔空吸附或穿墙机制。
- **触发条件**：只要玩家处于下落状态且前向轨迹预测落点为实体方块、预计会产生摔落伤害，救援逻辑即刻启动，不要求达到致命伤害门槛。预测落入深水等安全介质时不会触发。
- **摔落结算**：当玩家在下落时机与赶到的生物发生重叠并成功建立原版骑乘关系，本次累积的摔落距离将被清零。
- **无持续免伤**：成功骑乘仅化解本次着陆伤害，模组不提供任何无敌护盾或持续免伤。如果接住玩家的是苦力怕或僵尸，落地解除骑乘后其仍会按原本逻辑进行攻击。
- **骑乘与操控**：默认在安全着陆后解除骑乘；若在配置文件中开启 `keep-riding`，玩家落地后将保持骑乘状态，但这绝不会赋予玩家操纵生物移动、转向或飞行的能力。
- **生物调度与仇恨**：默认允许敌对生物参与救援，可在配置中排除；救援仅向生物的行为选择器注入临时移动目标，不会修改生物原本的攻击仇恨。
- **纯服务端实现**：不包含任何新客户端界面（GUI）或渲染修改。

## 平台支持与独立分包

本项目并非全版本通用的单一 JAR 文件，而是针对不同加载器与版本分别提供独立分包：

- **Forge**：`1.7.10` / `1.12.2` / `1.20.1`
- **Fabric**：`1.20.1` / `1.21.1`（专服专用，必须安装对应版本的 Fabric API）
- **NeoForge**：`1.21.1`

各版本独立构建，互不通用。

---

## 安装与运行须知

- **服务端部署**：请将对应版本的 JAR 文件放入专有服务端（Dedicated Server）的 `mods` 目录。
- **Fabric 环境限制**：Fabric 分包元数据限定为服务端环境（`environment: server`，仅注册 `entrypoints.server`），单机集成服务器不会加载该模组，且必须前置 Fabric API。
- **单机支持说明**：Forge 与 NeoForge 版本的单机客户端运行与免客户端安装尚未进行全面验证，目前不承诺单机环境的可用性。

---

## 配置与构建

- **配置格式与生效规则**：Forge 1.7.10 与 1.12.2 使用 `.cfg` 格式；现代 Forge 与 NeoForge 使用 COMMON `.toml` 格式；Fabric 由模组自行读写 Gson `.json` 格式（非 Fabric 官方配置 API）。修改配置必须在停服状态下编辑，重启服务端后生效。
- **源码构建**：在仓库根目录执行 `./gradlew buildReleaseJars`，六个目标的构建产物会分别输出到各子模块的 `build/libs/` 目录下，不会自动汇聚到 `build/release`。
- **详细说明**：有关黑名单实体配置、搜寻半径参数及历史版本 JDK 构建要求，请参阅[配置与构建说明](common/README.md)。
